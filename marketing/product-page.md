# seo-india: free India SEO audit skill for Claude Code

Audit any website for the Indian market in minutes. Free and open source.

## What it checks
- Language and script: Indic pages, language tags, hreflang
- Indian formats: ₹/INR, +91, PIN codes, address and schema fields
- Phone performance: JavaScript weight, images, lazy-loading
- Trust signals: WhatsApp, refund and privacy pages, GST, UPI/COD/EMI for shops
- Local presence: city-level schema, hours, geo
- Keyword planning: English-India, native-script, transliterated and Hinglish variants

## Honest limits
Reads one public page per run; no invented search volumes; cannot read sites that block bots; Lighthouse and Google Business Profile checks are reported as "unknown". Re-verify fast-changing facts before quoting them.
